## Описание

WT232 — универсальный Windows-терминал для COM-портов. Поддерживает HEX/TEXT/DUMP режимы, 75 макросов (5×15), скрипты с задержками, автоподключение USB-устройств по VID/PID, светлую и темную тему.

---

## Возможности

- **Режимы отображения:** HEX, TEXT, DUMP
- **Макросы:** 5 банков по 15 ячеек (всего 75 команд)
- **Скрипты** с поддержкой задержек (#DELAY) и остановки (#STOP)
- **Инлайн-HEX** внутри текста (обратные кавычки: `` `AA BB` ``)
- **Автоподключение** USB-устройств по VID/PID/серийному номеру
- **Кодировки:** ASCII, UTF-8, CP1251, CP866, CP1252, KOI8-R
- **Светлая и темная** темы оформления
- **Настраиваемый** размер шрифта
- **Эхо-режим** (отображение отправленных данных)
- **Автоматическая** повторная отправка (таймер)

### Управление потоком

- Нет / None
- XON/XOFF
- RTS/CTS
- RS-485 (RTS Toggle)

## Сборка из исходных кодов

Проект разработан в среде **Pelles C for Windows, версия 14.10**.

### Для сборки:

1. Установите [Pelles C](https://www.pellesc.de/)
2. Откройте файл проекта `WT232.ppj`
3. Выберите конфигурацию сборки: **Release** или **Debug**
4. Нажмите **Build (F7)**

### Конфигурации сборки:

| Режим | Описание |
|-------|----------|
| **Release** (рекомендуется) | Оптимизированный код, минимальный размер, максимальная производительность, без отладочной информации |
| **Debug** (для разработчиков) | Содержит отладочную информацию, позволяет использовать отладчик, упрощает поиск ошибок, больший размер файла |

## Установка

Программа не требует установки. Достаточно распаковать архив и запустить исполняемый файл `WT232.exe`.

Настройки сохраняются в файле `WT232.ini` в той же папке.

---

## Использование

1. Запустите `WT232.exe`
2. В окне настроек выберите COM-порт и параметры соединения
3. Нажмите **OK** для открытия терминала
4. Для отправки данных введите текст в поле ввода и нажмите **SEND**
5. Принимаемые данные отображаются в главном окне

## Макросы

Для открытия панели макросов нажмите кнопку **M1..M5** в нижней части главного окна.

- **RUN/EDIT** — Переключение режима: выполнение или редактирование макросов
- **LABEL/CMD** — Переключение отображения: название или команда
- Редактирование: нажмите на ячейку в режиме EDIT

## Скрипты

Формат файла скрипта (`.txt`):

```txt
1000              - Глобальная задержка (мс) в первой строке
#DELAY 500        - Задержка перед следующей командой
#STOP             - Остановить выполнение скрипта
#...              - Комментарий (игнорируется)
команда 1         - Отправляемая команда
команда 2         - Отправляемая команда
#STOP
```
**Примечание**: Без директивы #STOP скрипт выполняется циклически.

-------------------------------------------------------------------------------
Инлайн-HEX
-------------------------------------------------------------------------------

Внутри текстовых команд можно использовать HEX-значения в обратных кавычках:
```txt
  AT+CPIN=`0D0A`    - Отправить AT+CPIN с CR+LF в конце
  `01 02 03 04`     - Отправить байты 0x01 0x02 0x03 0x04
```
Пробелы внутри кавычек игнорируются. Регистр не важен.

-------------------------------------------------------------------------------
Файл настроек
-------------------------------------------------------------------------------

Все настройки сохраняются в файле WT232.ini в той же папке, что и программа.
При повреждении файла настроек программа автоматически создает резервную
копию WT232.ini.bak и восстанавливает настройки.
