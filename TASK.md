## Активная задача

### Задача «Выход из WAIT по любой клавише везде + единообразная подсказка» [IN PROGRESS]
- **Цель:** #WAIT завершается любой клавишей во всех точках (макрос-панель + терминал, оба раннера); подсказка (лейбл правее RUN) единообразна во всех окнах — «любая клавиша», а не конкретный ключ.
- **Как:**
  1. Гейт `want == WAIT_ANY || wp == want` убран из всех 4 точек resume (панель: макрос + глобальный; терминал: глобальный + цикл макрос-банков) — любая клавиша, пришедшая во время ожидания, безусловно завершает его и скрипт продолжается.
  2. Единообразный текст подсказки: обе wait-ветки `RunNext*` пишут фиксированный «WAIT: любая клавиша» (ранее `WAIT: <ключ>` через `wait_key_name` — различался по файлам/окнам).
  3. Доки: README (директивы + пример), справка макросов, справка терминала, `g_scriptExample`: «выход — по любой клавише; аргумент — подсказка».
- **Текущее состояние:**
  - сделано: код (4 точки resume + единый лейбл в обоих раннерах), README + 3 справки; сухой pocc OK (CC_EXIT=0)
  - не начато: IDE-пересборка пользователем + подтверждение
- **Следующие 2–3 шага:**
  1. Пользователь: Build в IDE → `#WAIT SPACE`: выход и по SPACE, и по TAB/F5 (любая, в обоих окнах); `#WAIT` — подсказка «любая клавиша» во всех окнах
  2. Подтверждение → `[RESOLVED]`
- **Решения:** | что | почему |
  | аргумент клавиши = подсказка, не гейт; выход по любой | запрос пользователя «выход из WAIT по любой клавише везде»; гейт блокировал выход «не той» клавишей |
  | фиксированная подсказка «WAIT: любая клавиша» во всех окнах | подсказки расходились (`WAIT: SPACE` vs `WAIT: любая клавиша`); единообразие соответствует поведению «любая клавиша» |
- **Открытые вопросы:** —
- **Файлы для чтения:** `main.c` — `WM_KEYDOWN` панели (~2186) и терминала (~2808), wait-ветки `RunNext*` (~1543/1615, единый лейбл), справки (~2273, ~2948), `g_scriptExample` (~392); `README.md` — «Директивы»
- **Проверка:** сухой pocc OK (CC_EXIT=0); тест: `#WAIT SPACE` завершается любой клавишей в обоих окнах, подсказка единообразна
