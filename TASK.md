### Задача «Справка макросов: описание скриптов + примеры» [EXECUTED]
- **Цель:** Расширить справку (?) окна макросов: раздел «Скрипты макросов» — файлы, кнопки, синтаксис, директивы + готовый пример `.wts`.
- **Артефакт:** `main.c` — текст `macroHelp` в `MacroPadWndProc` (секция `IDC_MACRO_BTN_SCRIPT_INFO`)
- **Как:**
  1. «СКРИПТЫ МАКРОСОВ»: файл `[имя_программы]#N.wts` (индекс банка, UTF-8), `SCRIPT` — создаёт с примером + Блокнот, `RUN/STOP` — выполняет независимо от терминала.
  2. «ДИРЕКТИВЫ»: первая строка-число = глобальная задержка; `#DELAY n`; `#STOP` (без него — зацикливание); комментарий только строкой целиком.
  3. Пример скрипта: `500`, `AT`, `#DELAY 1000`, `A0`FF,00,0D0A``, `005` (DEC), `#STOP` — покрывает HEX-2/HEX-4+/DEC-3 инлайн-синтаксис.
  4. Строка `MODE: EDIT` дополнена кнопкой Send (фича v0.6.4 в справке не была).
- **Текущее состояние:**
  - сделано: `main.c` — правка `macroHelp`; сборка `CC_EXIT=0`, `LINK_EXIT=0` (`output`-рецепт)
  - не начато: тест у пользователя (окно макросов → `?`)
- **Следующие 2–3 шага:**
  1. Пользователь: `WT232.exe` → окно макросов → `?` — проверить, что пример читается и соответствует поведению парсера.
  2. Подтверждение → `[RESOLVED]`.
- **Решения:** | что | почему |
  | меняю только справку окна макросов | запрос пользователя: «окно макросов помощь»; глобальная справка терминала (L2772) — отдельная задача при желании | 
  | «Ошибка токена отбрасывает всю строку» в тексте справки | фактическое поведение парсера (`parse_text_with_inline_hex` → 0 = ничего не слать); объясняет «пустые» отправления | 
  | пример без inline-комментариев на строках команд | в парсере комментария только целая строка `#...`; конец строки с `#` отправится как часть команды |
