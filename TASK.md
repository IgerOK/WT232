## Активная задача

### Задача «Директива #WAIT в скриптах + v0.6.5» [EXECUTED]
- **Цель:** Директива `#WAIT [KEY]` — пауза скрипта до нажатия клавиши (SPACE/ENTER/ESC/F1-F12/A-Z/0-9; без аргумента — любая) в макроскриптах и глобальном скрипте; версия → v0.6.5.
- **Как:**
  1. `ScriptItem.waitKey`; парсер в `LoadGlobalScript`/`LoadMacroScript` (`#WAIT`, `#WAIT <имя>`; неизвестное имя → строка как комментарий); `parse_wait_key`/`wait_key_name`.
  2. Запуск: `RunNextMacroScriptCommand`/`RunNextGlobalScriptCommand` при waitKey — пауза без таймера, статус `WAIT: <ключ>` (подпись панели) / кнопка `WAIT` (терминал), `SetFocus` на окно.
  3. Возобновление: `WM_KEYDOWN` в `MacroPadWndProc` и `TerminalWndProc` (совпадение или любая) → таймер со следующего пункта; `Stop*` чистят waitKey; реконнект-таймер не будит ожидающий скрипт.
  4. Текст: справка (?) окна макросов (`#WAIT` + строка в примере), справка (?) скрипта терминала (Директивы + `ПРИМЕР (#0.wts)` с `#WAIT SPACE`), шаблон `g_scriptExample`, README (журнал/директивы/шаблон), `APP_VERSION` v0.6.5.
- **Текущее состояние:**
  - сделано: код `main.c` (парсер, раннеры, WM_KEYDOWN, UI, обе справки с примерами, шаблон, версия); README; сборка OK.
  - в работе: пользовательский тест: `500/A/#WAIT SPACE/B/#STOP` → «видно AB, ожидания нет». Усилен парсер (21f4f57): `parse_wait_key` берёт первый токен, триггер допускает таб/пробел. По запросу пользователя примеры/шаблон переведены на `#WAIT` без аргумента (любая клавиша — самая устойчивая форма, не зависит от парсинга имени)
  - не начато: повторный тест пользователя после пересборки
- **Следующие 2–3 шага:**
  1. Пользователь: `.wts` с `#WAIT SPACE` → RUN макроскрипта → пауза со статусом → пробел → продолжение; глобальный скрипт — клавиша в терминале.
  2. Подтверждение → `[RESOLVED]`.
- **Решения:** | что | почему |
  | ожидание в окне (SetFocus + WM_KEYDOWN), не глобальный hook | проще и безопаснее; документировано в справке («нажимай в этом окне») | 
  | неизвестное имя клавиши → строка игнорируется (комментарий) | неявный fallback на «любую» был бы непрозрачным | 
  | кнопка RUN в ожидании = «WAIT», клик = стоп | явный выход из паузы без клавиши | 
  | `parse_wait_key` берёт первый токен, триггер `#WAIT` допускает таб/пробел после | пользовательский тест: `#WAIT SPACE` с хвостовым пробелом/табом тихо уходила в комментарий («видно AB, ожидания нет») | 
- **Открытые вопросы:** —
- **Файлы для чтения:** `main.c` — `parse_wait_key` (перед LoadGlobalScript), `RunNextMacroScriptCommand`/`RunNextGlobalScriptCommand`, `WM_KEYDOWN` в панели/терминале; `README.md` — «Директивы»
- **Проверка:** сборка; тест сценария WAIT в макроскрипте и глобальном скрипте
