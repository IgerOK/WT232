## Активная задача

### Задача «Предупреждение WAIT в строку правее кнопки RUN» [IN PROGRESS]
- **Цель:** предупреждение о #WAIT («WAIT: <ключ>») выводить не в RX-область терминала, а в строку статуса правее кнопки RUN (макрос-панель + терминал глобального скрипта); маркеры не пишутся в лог устройства.
- **Как:**
  1. Новые лейблы: `IDC_MACRO_WAIT_LBL` в макрос-панели (ряд кнопок, правее RUN; раскладка — `LayoutButtons`), `IDC_SCRIPT_WAIT_LBL` в терминале (правее глобальной кнопки RUN, `WM_SIZE`); когда не ждут — пустые.
  2. Вход в ожидание: текст лейбла = компактный `WAIT: <ключ>`; из обоих раннеров убрано письмо в терминал; `append_wait_resume_line` удалена; `hStatusLbl` остаётся только `MODE: RUN/EDIT`.
  3. Возобновление (4 точки) и `Stop*` — очистка соответствующего лейбла.
- **Текущее состояние:**
  - сделано: все правки в `main.c` (лейблы в обоих окнах, оба раннера, все точки resume/stop); сухой pocc OK (CC_EXIT=0)
  - не начато: IDE-пересборка пользователем + визуальная проверка
- **Следующие 2–3 шага:**
  1. Пользователь: Build в IDE → банк 0 (`WT232#1.wts`): RUN → `A` → в строке правее кнопки RUN `WAIT: любая клавиша`, терминал чистый → клавиша → `B` → стоп (#STOP); глобальный (`WT232#0.wts`) — лейбл правее глобальной кнопки RUN в терминале
  2. Подтверждение → `[RESOLVED]`
- **Решения:** | что | почему |
  | компактный текст лейбла `WAIT: <ключ>` (не полная фраза) | ширина строки ограничена (~163 px при размере панели по умолчанию); полная формулировка в справке |
  | лейбл чистится при возобновлении/стопе; RX-область терминала маркерами больше не заполняется | RX-область — лог устройства, UI-сообщениями его не засоряем |
- **Открытые вопросы:** —
- **Файлы для чтения:** `main.c` — `IDC_MACRO_WAIT_LBL`/`IDC_SCRIPT_WAIT_LBL` (стр. 158/173), `g_hWaitLblScript`/`hWaitLbl` (стр. 250/336), `LayoutButtons` (~стр. 2104), wait-ветки `RunNext*` (~стр. 1546/1618), `WM_KEYDOWN` панели (~стр. 2190) и терминала (~стр. 2793); `.notes/dry-compile.ps1`
- **Проверка:** сухой pocc OK (CC_EXIT=0); IDE-сборка пользователем; чек: предупреждение в строке правее RUN, терминал чистый
